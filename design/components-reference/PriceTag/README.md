# PriceTag

Le prix en Syne 800 avec ses deux promesses toujours visibles : livraison gratuite et paiement à la livraison.

**Props :** `price` (89), `currency` (« TND »), `compareAt` (prix barré, uniquement s'il a réellement existé), `shippingLabel`.

La transparence est l'argument : ne jamais cacher de frais ailleurs que dans ces puces.
