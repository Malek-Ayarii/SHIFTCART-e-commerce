# LandingPage

Vues 1 et 2 assemblées : landing mobile (navbar, hero + story UGC, Pack Barista, calculateur, contenu du pack, avis, CTA final, CTA collant) et checkout express en bottom sheet.

**Props :** `price`, `videoSrc`, `videoPoster`, `reviews`, `whatsappNumber`, `onOrder(order)`, `height`.

Ordre des sections figé : promesse → preuve vidéo → offre → argument financier → contenu → preuve sociale → relance. Tous les CTA ouvrent le même bottom sheet.
