# TextField

Champ texte avec libellé visible au-dessus, 52px de haut, texte 16px (évite le zoom iOS).

**Props :** `label`, `hint`, `error` (message affiché sous le champ, bordure `danger`), `onValueChange(value)`, plus tous les attributs `<input>`.

Le placeholder montre un exemple de format, jamais le libellé. Erreur au blur, effacée dès que la saisie redevient valide.
