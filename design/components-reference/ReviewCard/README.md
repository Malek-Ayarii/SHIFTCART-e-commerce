# ReviewCard

Avis client court : étoiles, citation en gras, prénom + gouvernorat, mention « Achat vérifié ».

**Props :** `name`, `city`, `text`, `rating` (0–5), `verified`.

N'affiche que de vrais avis de vrais clients, avec leur accord. `verified` seulement si l'avis est rattaché à une commande livrée. Les textes de la maquette sont des placeholders à remplacer avant la mise en ligne.
