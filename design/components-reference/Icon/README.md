# Icon

Icônes Lucide (stroke 2, 24px) intégrées au bundle pour ne charger aucun fichier sur réseau 3G.

**Props :** `name` (une clé de la liste : menu, cart, play, pause, check, x, chevronDown, whatsapp, clock, printer, truck, star, package, coffee, thermo, gift, banknote, zap, pin, refresh, undo, trendUp, trendDown, grip, calendar, shield, alert), `size` (20 par défaut), `label` (rend l'icône lisible par les lecteurs d'écran ; sinon `aria-hidden`).

L'icône prend `currentColor` : colore son parent. Taille 16 dans le texte, 20–24 dans les boutons.
