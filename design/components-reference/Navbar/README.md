# Navbar

Barre discrète et collante (56px) : menu, wordmark centré, panier qui ouvre directement le checkout.

**Props :** `count` (pastille orange sur le panier), `onMenu`, `onCart`. Cibles de 44×44px.

Pas de liens de navigation multiples : le tunnel est one-page, le panier n'est qu'un raccourci vers le bottom sheet.
