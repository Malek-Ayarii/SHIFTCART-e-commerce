# GovernorateSelect

Menu déroulant natif stylisé des 24 gouvernorats, avec « Les plus demandés » en tête (Tunis, Sousse, Sfax, Ariana, Ben Arous).

**Props :** `value`, `onChange(gov)`, `onBlur`, `error`, `popular` (liste à mettre en tête), `label`.

Un `<select>` natif : sur mobile il ouvre la roue du système, plus rapide qu'une liste custom. La valeur sert ensuite aux rapports par gouvernorat côté admin.
